# 👑 Basit AI Interview Pro — Sovereign AI Interview Intelligence OS

> **Full-Stack Autonomous Technical, System Design, Live Coding & Behavioral Interview System**  
> Cloned & upgraded from `basit-jarvis-ai` with zero-npm-dependency native Node.js architecture.

---

## 🌟 Key Features

1. **Multi-Role Technical & Behavioral Catalog**:
   - Full-Stack Software Engineer
   - Senior Frontend Engineer
   - Backend Systems & Cloud Architect
   - AI / Machine Learning Engineer
   - DevOps & Cloud Architect
   - Data Scientist & Analytics Lead
   - Distributed System Architect
   - Engineering Leadership & Culture (STAR method)

2. **Multi-Model Frontier Intelligence**:
   - Sub-second conversational responses powered by **Groq Llama 3.3 70B**
   - Deep reasoning via **Google Gemini 2.5 / 2.0 Flash**
   - High-availability fallbacks to OpenRouter, OpenAI, and intelligent built-in heuristic engines.

3. **Live Voice & Interactive Video**:
   - Candidate live webcam stream with focus tracking
   - Web Speech API Speech-to-Text (STT) real-time transcription
   - Text-to-Speech (TTS) natural AI interviewer voice with reactive canvas waveform
   - Anti-cheat tab-switch detection & integrity audit

4. **Live Coding Sandbox**:
   - In-browser code editor supporting JavaScript and Python
   - One-click **Run & Verify** with automated edge-case test pass/fail breakdown
   - Real-time time & space complexity analysis (e.g. $O(n)$, $O(1)$)

5. **Automated Executive Scorecards & Hiring Verdicts**:
   - Overall Score (0-100) & Committee Verdict (`STRONG HIRE`, `HIRE`, `LEAN HIRE`, `NO HIRE`)
   - 5 Dimensional Radar Metrics (Technical, Problem Solving, Communication, Architecture, Leadership)
   - Question-by-question audit with candidate transcript vs. ideal benchmarks
   - Actionable career roadmap and printable/downloadable PDF report

6. **Historical Archive**:
   - Persistent session storage in `data/interviews.json`
   - Archive dashboard to review, replay, or delete past candidate interviews.

---

## 🚀 One-Click Launch

Double click `START_AI_INTERVIEW.bat` or run:

```bash
cd /d "e:\basit-ai-interview"
node server.js
```

Open your browser at:
`http://localhost:8090`
